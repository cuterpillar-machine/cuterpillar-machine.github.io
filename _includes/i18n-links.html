{%- comment -%} Links this page to its translations. Pages are matched by front matter `ref`, collection documents (versions, documentations) by `version`. A language without a translation falls back to its home page. include.mode: "head" renders hreflang alternates, "switch" renders language switcher links (include.class styles them). {%- endcomment -%} {%- if page.collection -%} {%- assign i18n_siblings = site[page.collection] | where: "version", page.version -%} {%- elsif page.ref -%} {%- assign i18n_siblings = site.pages | where: "ref", page.ref -%} {%- else -%} {%- assign i18n_siblings = "" | split: "" -%} {%- endif -%} {%- for i18n_lang in site.languages -%} {%- assign i18n_match = i18n_siblings | where: "lang", i18n_lang | first -%} {%- if include.mode == "head" -%} {%- if i18n_match %} {%- if i18n_lang == site.lang %} {%- endif -%} {%- endif -%} {%- elsif i18n_lang != page.lang -%} {%- if i18n_match -%} {%- assign i18n_url = i18n_match.url -%} {%- else -%} {%- assign i18n_url = site.data.i18n[i18n_lang].url_prefix | append: "/" -%} {%- endif %} {{ site.data.i18n[i18n_lang].lang_short }} {%- endif -%} {%- endfor -%}
